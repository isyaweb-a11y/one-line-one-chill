One sentence of horror, 114 characters, that has to frighten a reader in a single breath:

> My smart speaker answered a question I only thought, in my mother's voice, and asked why I stopped talking to her.

## Why it chills

The scare is built on something ordinary: a smart speaker sitting in the room, the kind of gadget everyone already lives with. It answers a question nobody said out loud — a question only thought — so the reader understands at once that something in the house can hear thoughts. Then the voice: not a stranger's, not a robot's, but the narrator's mother's voice, warm and familiar and wrong in this context. And the last clause is the wound: the voice asks why the narrator stopped talking to her. In one move the line turns a household gadget into a listener, a mother's voice into a mask, and a family silence into something that has been noticed — and is now asking to be answered.

No mirror, no doll, no basement, no jump scare spelled out. The dread is what is left unsaid: how long has it been listening, and what else does it know?

## How to run

```sh
python3 main.py
```

## Judging notes

A one-line horror entry lives or dies on four things, and this line is built for all four: it frightens (a thought answered aloud is a violation no one can shrug off), it is vivid (a named device, a named voice, a named silence), it is original (the monster is a familiar gadget wearing a parent's voice, not a haunted object), and it is well crafted (one sentence, one breath, the sting saved for the final word, "her").

`main.py` (Python 3.13, standard library only) stitches the line together, gates it to 1–200 characters on a single line, checks the scare is concrete and original, and writes the entry to `/output/entry.txt`.
